# Impacto Pinturas — Landing page

Landing page estática (HTML/CSS/JS puro) da Impacto Pinturas. Deploy automático na Vercel a cada push na `main`.

- `index.html` — página completa
- `assets/` — fotos, favicon e imagem de compartilhamento
- WhatsApp: números e textos no `<script>` ao final do `index.html` (objeto `NUM`)
